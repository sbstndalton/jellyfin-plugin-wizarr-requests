Access requests

Review the name and note before approving. Approval creates one single-use Wizarr invitation, valid for seven days; it does not create an account.

Applicants return to their private status link to collect the invitation. You can also copy it here and send it yourself. Approved invitations appear in Wizarr and Helmarr’s Wizarr list.

Connection settings
An explicit library selection is required. Downloads, live TV and uploads remain disabled.
